

Similar to the  ~/rhplay/lmlevelnames/  subdir we created before I want to create a  ~/rhplay/lmlevelinfo  To host resources for
analyzing actual Level Data from a ROMfile  instead of just level names.

Please look over the code in ~/rhplay/refmaterial/snesrev_smw/assets/
And the following files:
 ~/rhplay/refmaterial/snesrev_smw/assets/
~/rhplay/refmaterial/SMW-Data/Misc/LevelTables.asm 


And the Wiki text at  ~/rhplay/refmaterial/Level_Data_Format.txt
For information reference about Lunar Magic headers found in SMW romhack files (.sfc) files.
And   ~/rhplay/refmaterial/SMW-Data/Misc/MWL\ File\ Format.md 
for some information about the MWL file format.

The first goal is to create an additional utility similar to a thing like  ~/rhplay/lmlevelnames/level_reader.c 
it would be run at command line  it would run like

 level_info1 { <OPTION> |  <FILENAME> <LEVEL ID> [-o <OUTPUT FILE>] ... }
 
Where  LEVEL ID is the Lunar Magic  Level ID   such as 0x10A     or 10A

By default the display target is human readable, and
     -j  or   --json    would be an option to emit the data in JSON format.
     -m  or   --mwl     would be option to extract the level data to the same type of MWL file as used by Lunar Magic (Output file option mandatory for MWL output).
     
By default summary data is to be printed, and   something such as
     --data=all
     --data=none
	 --data=<comma separated liskt>
	 --data=allobjects

Would be options to in the future include some or all additional data sections that may be added in the future.
For example

level_info1 --data=objects,fulldata --json example_input.sfc 0x100  -o example_output.json



level_info1 example.sfc 0x100
