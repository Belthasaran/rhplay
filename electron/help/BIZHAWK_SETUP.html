BizHawk Download / Setup Instructions

Use BizHawk (EmuHawk) to launch SMW ROMs from RHTools.

Download and SNES core info

See the TASVideos BizHawk SNES guide: BizHawk / SNES on TASVideos

Setup

  1. Download and install BizHawk from the official project site linked from TASVideos.
  2. Run EmuHawk manually at least once before using it from RHTools.
  3. For SNES, BizHawk includes snes9x (casual play) and bsnes (TAS-oriented) cores.
Set the BizHawk executable path in RHTools Emulator Config. Typical Windows path: C:\Program Files\BizHawk\EmuHawk.exe
