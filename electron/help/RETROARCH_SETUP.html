RetroArch Download / Setup Instructions

Use RetroArch with the Snes9x core to launch SMW ROMs from RHTools.

Download

Download RetroArch

Install and first run

  1. Download and install RetroArch for your platform.
  2. Run RetroArch manually at least once before using it from RHTools.
  3. In RetroArch, open Online Updater → Core Downloader.
  4. Install Nintendo - SNES / SFC (Snes9x) — choose the entry with no year in the name.
After installation, set the RetroArch executable path and SNES core path in RHTools Emulator Config. Typical Windows paths:
  • C:\RetroArch-Win64\retroarch.exe
  • C:\RetroArch-Win64\cores\snes9x_libretro.dll
